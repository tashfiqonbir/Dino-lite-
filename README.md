# 🦖 Chrome Dino Terminal Game

## Creator ( Tashfiq Onbir) 

Google Chrome এর বিখ্যাত Dino Game এখন তোমার Termux এ!  
কোনো Internet লাগবে না। শুধু Python দিয়েই খেলো 😎

### ✨ Features

- **Auto Running** - নিজে নিজে দৌড়াবে
- **Speed Increase** - Score বাড়লে Game Fast হবে
- **Cactus Obstacles** 🌵 - পার করে High Score তোলো
- **Emoji Graphics** - সুন্দর UI
- **Lightweight** - মাত্র 50 লাইনের code
- **100% Offline** - Termux এ Offline খেলো
